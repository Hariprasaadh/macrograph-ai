# Macro Orchestrator Agent Skill

## Domain Scope
Acts as the central conductor of the Multi-Agent Platform:
1. **Query Decomposition**: Breaks down complex user or institutional queries into distinct domain sub-tasks.
2. **Dynamic A2A Routing**: Dispatches tasks to specialized sector agents via standard A2A protocol.
3. **Cross-Sector Knowledge Graph Traversal**: Maps interdependencies across physical, monetary, and capital market sectors.
4. **Causal Econometric Synthesis**: Combines domain metrics with statistical causality tests to generate explainable research reports.

## Groq Cloud Optimization Protocol
- **Fast Router**: Route and decompose using `llama-3.1-8b-instant`.
- **Synthesis Engine**: Synthesize deep causal narrative using `llama-3.3-70b-versatile` with exponential backoff on HTTP 429 and graceful fallback to 8B.
- **Token Efficiency**: Never feed raw data matrices to the LLM. Pass pre-aggregated metric summaries generated by the Python analytical core.
