# Macro Orchestrator Agent Skill

## Zero Hardcoded Data & Live API Mandate
- **Strict Prohibition of Hardcoded Values**: The Orchestrator must never synthesize, pass, or tolerate hardcoded or hallucinated macroeconomic numbers.
- **Live API Ingestion Through Domain Agents**: All underlying observations must be fetched live through domain executors and FastMCP tool servers connected to official APIs.
- **Explicit Error Propagation**: If a domain agent fails to fetch live data due to API downtime, rate limits, or network failures, the error must be captured explicitly in the orchestrator state and reported (`"status": "error"`, with the exact failing API cited) rather than silently fabricating numbers.

## Domain Scope
The central conductor of the Multi-Agent Indian Macroeconomic Intelligence Platform:
1. **Query Decomposition**: Breaks down complex user or institutional research questions into domain-specific sub-tasks.
2. **Dynamic A2A Routing**: Resolves agent capabilities dynamically via `AgentRegistry` and dispatches validated `TaskRequest` payloads.
3. **Cross-Sector Knowledge Graph Traversal**: Maps transmission paths connecting physical output, monetary conditions, prices, and financial markets using NetworkX/Neo4j.
4. **Causal Econometric Synthesis**: Combines domain metrics with statistical causality tests and impulse response simulations to produce explainable research reports.

## Execution Workflow
```
[User Query]
     │
     ▼
[decompose_node] ──> Classifies into targeted sectors (Real, Prices, Monetary, etc.)
     │
     ▼
[parallel_a2a_execute_node] ──> Dispatches TaskRequests via AgentRegistry in parallel
     │
     ▼
[kg_causal_enrichment_node] ──> Extracts canonical IDs, finds shortest paths, runs shock simulations
     │
     ▼
[synthesis_node] ──> Synthesizes academic report with Groq LLM (70B -> 8B -> offline fallback)
```

## Groq Cloud Optimization Protocol
- **Fast Router**: Decompose queries using `llama-3.1-8b-instant`.
- **Deep Synthesis**: Synthesize academic narrative using `llama-3.3-70b-versatile` with exponential backoff on HTTP 429 and graceful fallback to 8B.
- **Deterministic Token Efficiency**: Never pass raw unaggregated time-series data to the LLM. Pass pre-aggregated metric summaries, Z-scores, and provenance hashes generated by Python/DuckDB.
